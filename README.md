# My Stock Research Lab — prototype 0.1

A personal Streamlit prototype for exploring transparent stock-screening rules.

## Important
- `sample_stocks.csv` contains synthetic illustrative data only.
- The companies and figures are fictional and must not be used for investment decisions.
- This prototype does not connect to live data and does not provide investment advice.

## Files
- `app.py` — Streamlit app
- `requirements.txt` — Python dependencies
- `sample_stocks.csv` — illustrative sample dataset

## Run locally (computer)
1. Install Python 3.11 or newer.
2. Open a terminal in this folder.
3. Run: `python -m pip install -r requirements.txt`
4. Run: `python -m streamlit run app.py`
5. Open the local URL shown in the terminal.

## Run from iPhone
An iPhone cannot conveniently run a Streamlit server locally. Use a browser-based coding environment or deploy through Streamlit Community Cloud connected to a GitHub repository. The app then runs on a cloud server and opens in Safari. Keep the repository private if available and do not add API keys or personal financial information to source files.
